# Nocturne AI Novel

A desktop AI visual-novel prototype with branching scenes and saved worlds.

`typescript` `react` `electron` `visual-novel`

[Portfolio](https://dr01d.info/projects)

## Run locally

```text
npm install
npm run dev
```

See [project documentation](README.project.md) for detailed setup, architecture and limitations.
